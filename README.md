## Minor project: spam detection

`minor_project.ipynb` builds a binary email classifier from `enron_spam_data.csv`:

- Combines email subject and message text, removes duplicates, and drops the date column.
- Splits the data into training and test sets (70/30).
- Converts text to TF-IDF features with English stop-word removal and 1–2 word n-grams.
- Trains and evaluates Multinomial Naive Bayes and Logistic Regression using classification reports and ROC-AUC.

## Movie-data collection

`8.ipynb` uses the [TMDB API](https://developer.themoviedb.org/docs/getting-started) to retrieve top-rated movies (up to TMDB's 500-page limit). It retries transient HTTP failures and saves the following fields to `movies.csv`:

- `id`, `title`, `original_language`, `overview`
- `popularity`, `release_date`, `vote_average`, `vote_count`

Create a TMDB API key and set the notebook's `API_KEY` value before running it. Treat this key as a secret; do not commit a personal key to the repository.

## Requirements

- Python 3
- Jupyter Notebook or VS Code with the Jupyter extension
- NumPy, Pandas, Matplotlib, Seaborn, scikit-learn, and Requests

Install the Python libraries if needed:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn requests jupyter
```

## Running the notebooks

1. Clone or download this repository.
2. Open the folder in Jupyter Notebook or VS Code.
3. Start with the notebook of interest and run its cells in order.
4. Keep each CSV dataset in the repository root so the notebook file paths resolve correctly. `movies.csv` can be regenerated by running `8.ipynb` with a valid TMDB API key.
